# Gentlemen’s Barber – Website

Gentlemen’s Barber Website is the official online platform for the barbershop. Built with **HTML, CSS, and JavaScript**, it provides customers with a professional digital presence where they can explore services, book appointments, purchase grooming products, and learn more about the brand.

## Key Features

### Home Page
- Hero section with branding, tagline, and promotional video/image.  
- Navigation bar for quick access to Services, Products, Booking, and Contact.  

### Services Page
- List of available barber services (Haircut, Beard Trim, Shave, Facial, etc.).  
- Each service includes description and pricing.  
- “Book Now” buttons link directly to the booking system.  

### Booking Page
- Customers select service, barber, date, and time.  
- Integrated form validation ensures correct input.  
- Confirmation message displayed after successful booking.  

### Product Store
- Catalog of grooming products available for purchase:  
  - Shaving Cream  
  - Professional Clippers  
  - Hair Conditioner  
  - Beard Balm  
  - Facial Cleaner  
  - Barber Cape  
- Products displayed with images, descriptions, and prices.  
- Add to cart functionality with cart total displayed.  
- Checkout form for payment confirmation.  

### About Page
- Information about Gentlemen’s Barber brand and team.  
- Mission statement and values.  
- Contact details and location map.  

### Contact Page
- Contact form for inquiries and feedback.  
- Integrated email or backend script to send messages.  
- Social media links for extended engagement. 

## Tech Stack we implemented in the website
- **Frontend:** HTML5, CSS3, JavaScript.  
- **Styling:** External CSS stylesheet with responsive design.  
- **Interactivity:** JavaScript for booking forms, cart management, and dynamic content.  
- **Backend (future integration):** PHP / Firebase for database and authentication.
  
## End Goal
The Gentlemen’s Barber Website was developed to:
- Provide a professional online presence for the barbershop.  
- Allow customers to explore services and products before visiting.  
- Simplify appointment booking through an accessible web interface.  
- Offer online product purchasing for convenience.  
- Strengthen brand identity with a polished design and clear navigation.
